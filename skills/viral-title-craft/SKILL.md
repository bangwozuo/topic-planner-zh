# 爆款标题锻造

把一个选题锻造成 3 个不同句式的候选标题，标注公式与适用场景，供发布前
A/B 择优。

不做的事：不写正文；不做「必然爆」的承诺——标题只负责点击率。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_01_sk05` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 选题策划师 |
| 能力族 | 内容生成型 · 标题创作 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | ★★★★★（WF3 主力步骤，各平台分发复用） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **六大标题公式**：数字锚点 / 反差悬念 / 身份代入 / 结果前置 / 疑问钩子 /
   警告避雷，每题 3 标题须来自 3 种不同公式（同公式换词不算 A/B）
2. **平台字数规则**：小红书 ≤20 字、抖音 ≤30 字、公众号会话列表约 13 字
   截断——钩子必须在前 12-15 字完成
3. **悬念兑现约束**：标题埋的钩子须在正文前 30% 内开始回答，否则举报率
   上升、完播率崩塌
4. **合规自检**：极限词（《广告法》第九条）零容忍、灾难钩子禁止、
   人设词须有依据、数字须真实可验证
5. **A/B 判定闭环**：48h 后点击率最高的公式沉淀进每周复盘权重

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `topic` | string | ✅ | 选题（含核心内容方向） |
| `platform` | string | ✅ | 小红书 / 抖音 / 公众号 / B站 / 知乎 |
| `audience` | string | ⬜ | 目标人群（用于身份代入公式） |
| `facts` | array | ⬜ | 可用于标题的真实数据点（如「47 天涨 1 万粉」） |

## 输出规格

- `titles`：3 个候选标题（标题 / 字数 / 公式 / 吸引人群 / 风险提示）
- `advice`：主发建议 + A/B 备选 + 正文兑现位
- `checks`：六项自检结果

## 使用步骤

### 方式一：纯提示词（唯一方式，本技能为纯提示词资产）

1. 打开任意支持自定义提示词的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 提供选题 + 平台（+ 目标人群与真实数据点）
4. 得到 3 标题与发布建议，**发布前人工确认**

### 字数核对（可选）

标题字数建议用平台后台的字数统计核对；本技能不含脚本，字数与展示截断
以各平台官方最新说明为准。

## 边界（不做的事）

- ❌ 不编造数据、身份、效果承诺
- ❌ 不用极限词、不蹭灾难、不写恐吓式标题（「不看后悔」「速删」）
- ❌ 不做同公式换词的伪 A/B
- ❌ 不承诺必然爆——只负责点击率，正文决定账号生死
- ❌ 平台规则多变，以官方最新公示为准

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "topic": "下班后做副业的第一个月复盘：接单渠道、踩坑与真实收入",
  "platform": "小红书",
  "audience": "上班族，想搞副业但没启动过",
  "facts": ["副业第一个月收入 3200 元", "踩坑 3 次", "每天投入 2 小时"]
}
```

**输出**（按 prompt 规则产出的标题示例）：

| # | 标题 | 字数 | 公式 | 风险提示 |
|---|---|---|---|---|
| 1 | 下班 2 小时搞副业，第一个月我赚了 3200 | 19 | 结果前置 | 收入数字须与截图一致 |
| 2 | 上班族副业第一课：接单前先避开这 3 个坑 | 19 | 警告避雷 | 「坑」须在正文列全 |
| 3 | 为什么你不敢开始副业？我先替你踩完了 | 18 | 疑问钩子 | 前 30% 内要开始回答 |

发布建议：主发 #1（结果前置对小红书收藏率友好）；#2 次日重发 A/B；
正文前 30% 必须给出收入明细结构，兑现 #1 的数字承诺。

## 合规声明

- 本技能输出为 **AI 辅助生成内容**，标题发布前必须经创作者人工确认
- 极限词、灾难钩子、伪造人设一律禁止（《广告法》第九条与平台社区规范）
- 标题中的数字须真实可验证，引用数据注明出处
- 请按所在平台要求完成 AI 生成内容标识
