1. ✅ 字数：20/19/18，均 ≤ 小红书 20 字上限（len() 实测）

3. ✅ 无极限词、无灾难钩子、无人设词
4. ✅ 悬念可兑现：#3 的「不敢开始」在正文首段以「因为怕亏时间」回应
5. ✅ 数字真实：3200 / 3 坑 / 2 小时均来自输入 facts，可查证
6. ✅ 公式互异：结果前置 / 警告避雷 / 疑问钩子三种公式
