# 爆款结构拆解

把一条爆款内容拆成带时间戳的功能段结构，抽成可复用的结构模板，并标注
适配的内容类型。

不做的事：不洗稿、不逐句复刻——拆的是「为什么观众看完了」，不是
「他说了什么」。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_01_sk06` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 选题策划师 |
| 能力族 | 内容分析型 · 结构拆解 |
| 复杂度 | `S` |
| 阶段 | `P1` |
| 复用度 | ★★★★（WF3/WF4 引用其模板规则） |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **五段功能结构**：钩子（前 3 秒）/ 建立期待（3-10 秒）/ 价值密度
   （中段 50-60%，每 15-20 秒一个信息点）/ 反转高潮（约 70% 处）/
   CTA（最后 10%，只留一个动作）
2. **六类钩子标注**：反常识开场 / 结果前置 / 身份点名 / 悬念缺口 /
   争议站队 / 场景危机
3. **量化基准判质量**：5 秒完播 ≥50%、整体完播 ≥30%、点赞率 ≥3%、
   评论率 ≥0.5%、收藏率 ≥8%（小红书），数据缺失只拆结构不判质量
4. **模板生成**：同结构样本 ≥2 条才抽可复用模板，单样本只出「观察样本」
5. **适配判断**：明确模板适合与不适合的内容类型，防东施效颦

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `samples` | array | ✅ | 爆款样本：title / transcript（逐字稿）/ segments（时间轴）/ stats（点赞/评论/完播，可缺省） |
| `purpose` | string | ⬜ | 拆解用途（套用到什么内容类型） |

样本来源：近 30 天点赞超账号均值 5 倍的爆款（对齐竞品追踪定义），
逐字稿为人工转写或平台字幕导出。

## 输出规格

- `structure`：结构表（起止时间 / 功能段 / 原文摘句 / 手法标注）
- `rhythm`：节奏曲线（信息点间隔，最长注水段定位）
- `template`：可复用填空模板（≥2 样本才产出）或「观察样本」标注
- `fitness`：适配 / 不适配的内容类型及理由

## 使用步骤

### 方式一：纯提示词（唯一方式，本技能为纯提示词资产）

1. 打开任意支持自定义提示词的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 提供爆款样本逐字稿 + 时间轴 + 数据（缺数据就标注缺失）
4. 得到结构表 / 节奏曲线 / 模板与适配判断，**套用前人工确认**

## 边界（不做的事）

- ❌ 不凭印象复原结构——没有逐字稿就明说
- ❌ 不洗稿、不逐句复刻——模板只到结构与手法层
- ❌ 不拆政治敏感、灾难事故类内容做模板
- ❌ 单样本不抽模板；不承诺「套用必爆」
- ❌ 不拆 10 万粉以上人设红利样本的结构当素人模板（只拆同量级）

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "samples": [
    {
      "title": "被裁员那天我在工位坐到凌晨：3 个动作保住赔偿金",
      "stats": {"likes": 41000, "comments": 860, "play": 620000, "completion": 0.38},
      "segments": [
        {"start": 0, "text": "被裁员那天，我在工位坐到了凌晨一点。"},
        {"start": 4, "text": "如果你也怕谈赔偿金吃哑巴亏，这 3 个动作先记住。"},
        {"start": 11, "text": "第一个动作：当天不要签任何字…"}
      ]
    }
  ]
}
```

**输出**（结构表节选）：

| # | 起止 | 功能段 | 原文摘句 | 手法标注 |
|---|---|---|---|---|
| 1 | 0-4s | 钩子 | 「我在工位坐到了凌晨一点」 | 悬念缺口 + 场景危机 |
| 2 | 4-11s | 建立期待 | 「这 3 个动作先记住」 | 数字承诺 |
| 3 | 11-52s | 价值密度 | 「第一个动作：当天不要签任何字…」 | 干货每 15s 一个 |
| 4 | 52-58s | 反转 | 「但最贵的其实不是赔偿金，是下一个 offer 的背景调查」 | 认知升级 |
| 5 | 58-62s | CTA | 「收藏起来，最好用不上」 | 单一动作 + 反向祝福 |

完播 38% ≥ 30% 及格线，点赞率 6.6% ≥ 5% 优秀——钩子与反转段有效。
单样本 → 标注「观察样本」，待同类第二样本后抽模板。
