## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 数据来源 | 仅支持平台公开展示数据的手动浏览/粘贴；不扒后台与商务数据 |
| leave-one-out 局限 | 账号仅 1-2 条记录时基准不稳定，已按规则不判，但意味着新对标号需积累数据 |
| 句式统计 | 词表法只覆盖数字锚点/疑问悬念/反差词三类，其他修辞（谐音、热梗）须模型补充 |
| 时效 | 竞品数据为采集时点快照，倍数随时间漂移，重大决策前建议重新采集 |
