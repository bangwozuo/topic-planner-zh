# 竞品动态追踪

盯住对标竞品账号，从他们的更新流里找出「哪条爆了、为什么爆、我能学什么」，
产出可执行的借鉴清单。

不做的事：不搬运、不洗稿、不抄袭——只拆解思路和结构。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_01_sk02` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 选题策划师 |
| 能力族 | 信息采集型 · 竞品分析 |
| 复杂度 | `M` |
| 阶段 | `P1` |
| 复用度 | ★★★★（WF1 第二步，复盘流程可引用） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **爆款判定**：单条点赞 > 该账号近 30 天点赞均值 × 5 = 爆款；
   均值按 leave-one-out 计算（爆款不抬高自己的基准），消除量级差异
2. **更新节奏**：近 30 天条数 ÷ 4.3 = 条/周；最近一条 ≥14 天 = 断更预警
3. **标题句式统计**：数字锚点 / 疑问悬念 / 反差词三类命中率，
   沉淀为句式模板库
4. **假阳性拦截**：评论点赞比异常（评论 < 点赞 1%）标疑似注水；
   平台活动加持、旧闻复爆、时运型热点单列

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `niche` | string | ⬜ | 本账号定位（用于句式套用方向） |
| `posts` | array | ✅ | 竞品发帖记录：account / platform / title / likes / comments / shares / days_ago |

数据来源：平台主页公开展示数据的手动浏览记录或截图转写（不扒私密数据）。

## 输出规格

- `rows`：帖子明细（点赞 / 基准均值 / 倍数 / 判定 / 标题句式）
- `overviews`：账号概览（条数 / 条均点赞 / 最高倍数 / 断更状态）
- 产物文件：`out/竞品追踪报告.xlsx`、`out/竞品互动对比.png`、`out/competitor_track.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 粘贴竞品账号近 30 天发帖记录
4. 得到爆款拆解与句式模板库（结构拆解与借鉴尺度由模型完成）

### 方式二：带脚本（精确计算 + 产出 Excel）

```bash
python scripts/competitor_track.py --input input.json --outdir out
python scripts/competitor_track.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/竞品追踪报告.xlsx` | 爆款明细（爆款行标红）/ 账号概览 / 汇总 |
| `out/竞品互动对比.png` | 各账号近 30 天条均点赞柱状图 |
| `out/competitor_track.json` | 机器可读结果，供 hotspot-aggregate-scan-flow 读取 |

**分工**：脚本做均值、倍数、节奏、句式统计（不漏算、自我稀释已修正）；
模型做结构拆解、句式模板提炼、可迁移性判断。数值以脚本为准。

## 边界（不做的事）

- ❌ 不编造竞品账号或数据
- ❌ 不教搬运、洗稿、逐帧翻拍——借鉴只到句式与结构层面
- ❌ 不扒需登录的私密数据（后台数据、商务报价）
- ❌ 数值计算以脚本输出为准
- ❌ 不做贬低性评判，只做事实拆解

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "niche": "职场成长/自媒体运营",
  "posts": [
    {"account": "职场老张", "platform": "抖音", "title": "被裁员那天我在工位坐到凌晨：3 个动作保住赔偿金", "likes": 41000, "comments": 860, "days_ago": 6},
    {"account": "职场老张", "platform": "抖音", "title": "面试反问环节的 3 个加分问题", "likes": 5200, "comments": 140, "days_ago": 11}
  ]
}
```

**输出**（脚本实跑，3 账号 10 条）：

| 判定 | 标题 | 点赞 | 基准均值 | 倍数 | 句式 |
|---|---|---|---|---|---|
| 🔥 爆款 | 被裁员那天我在工位坐到凌晨：3 个动作保住赔偿金 | 41000 | 5100.0 | 8.0 | 数字锚点 |
| 🔥 爆款 | 下班后搞副业 3 个月，收入从 0 到 8000 的路径 | 12500 | 1616.7 | 7.7 | 数字锚点 |
| ⚠ 断更预警 | 运营小笔记（最近更新 21 天前） | — | — | — | — |

汇总：爆款 2 条；「职场老张」条均点赞 12280 居首，更新节奏 1.2 条/周。
