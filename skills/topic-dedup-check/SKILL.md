# 选题去重校验

把今天的候选选题逐条与个人历史选题库比对，把重复的挑出来、相似的标注出来，
避免账号因自我重复被平台降权。

不做的事：不定选题、不评分——去重是下游选题包流程的前置关卡。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_01_sk03` |

| 所属员工 | 选题策划师 |

| 复杂度 | `S` |

| 复用度 | ★★★★★（WF2 主力步骤，选题包前必过） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **相似度分级**：去标点字符二元组，Jaccard 与包含度取大——
   ≥0.60 🔴 重复 / 0.40-0.60 🟡 相似 / <0.40 🟢 通过
2. **重做窗口**：历史题超过 90 天（粉丝记忆窗口）自动降一档，同题可翻新
3. **语义复核**（模型侧）：换说法同题、子集题、场景平移题的字面相似度低
   但语义重复，由模型逐条判断并改判
4. **差异化方向**：每条相似/重复给出换人群 / 换场景 / 换步骤数 / 换结果 /
   换立场 / 换失败面至少一个具体方向
5. **豁免规则**：系列内容（第 N 期）与节点年更题（节假日）标注豁免

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `candidates` | array | ✅ | 候选选题：title / source（来源可选） |
| `library` | array | ✅ | 历史选题库：title / days_ago（发布距今天数） |

历史库来源：选题知识库导出或用户粘贴；首次使用可先以空库起步。

## 输出规格

- `rows`：判定明细（最高相似度 / 最接近的历史题 / 判定 / 差异化方向）
- `summary`：候选数 / 重复 / 相似可重做 / 通过 / 阈值说明
- 产物文件：`out/选题去重清单.xlsx`、`out/dedup_check.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 粘贴候选选题与历史选题库
4. 得到分级判定与差异化方向（语义重复的复核由模型完成，这是脚本做不了的）

### 方式二：带脚本（精确计算 + 产出 Excel）

```bash
python scripts/dedup_check.py --input input.json --outdir out
python scripts/dedup_check.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/选题去重清单.xlsx` | 判定明细（重复行标红）/ 汇总 |
| `out/dedup_check.json` | 机器可读结果，供 topic-lib-dedup-match-flow 读取 |

**分工**：脚本做字面相似度与 90 天窗口判定（不漏算）；模型做语义重复复核
与差异化方向撰写。两者结果交叉核对，模型可改判但须说明理由。

## 边界（不做的事）

- ❌ 不编造历史选题库——库里没有就说没有
- ❌ 数值计算以脚本输出为准，对话不口算
- ❌ 不给「建议优化」空话——每条相似/重复必须落到具体差异化方向
- ❌ 只查自己的历史库；与竞品内容的重复走竞品追踪技能
- ❌ 不自动淘汰——重复项最终去留由人工确认

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "candidates": [
    {"title": "面试被问期望薪资怎么答：3 个话术模板", "source": "热榜候选"},
    {"title": "领导让你口头汇报时，先说结论再说理由", "source": "评论区提问"}
  ],
  "library": [
    {"title": "面试被问期望薪资怎么答：3 个话术模板", "days_ago": 35},
    {"title": "汇报工作先说结论：金字塔原理的 3 步用法", "days_ago": 120}
  ]
}
```

**输出**（脚本实跑，5 候选）：

| 判定 | 候选选题 | 最高相似度 | 说明 |
|---|---|---|---|
| 🔴 重复 | 面试被问期望薪资怎么答：3 个话术模板 | 1.00 | 与 35 天前历史题完全重合；方向：换人群、换场景、换步骤数 |
| 🟢 通过 | 领导让你口头汇报时，先说结论再说理由 | 0.25 | 字面通过；模型复核提示与「金字塔原理 3 步用法」语义同题，需改判 |

汇总：重复 1 / 相似可重做 0 / 通过 4；模型复核改判 1 条（语义同题）。
