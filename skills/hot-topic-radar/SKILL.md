# 全平台热点雷达

把各平台热榜/热搜里的噪声筛掉，产出「今天值得看的结构化候选池」，并按选题
四象限给出初步分级。

不做的事：不写文案、不定最终选题、不蹭灾难类热点。只做采集整合与分级。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_01_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 选题策划师 |
| 能力族 | 信息采集型 · 热点聚合 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★（WF1 主力步骤，WF4 热点回溯可引用） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **五源聚合**：抖音热榜 / 小红书热点榜 / 微博热搜 / 知乎热榜 / B站热门，
   统一记录标题、热度、排名、距首发小时数
2. **跨平台同话题合并**：标题二元组相似度 ≥ 0.55 合并（含长句 vs 短句改写），
   被 ≥2 平台收录的真热点热度上浮 10%
3. **热度归一化 + 时效衰减**：log10 归一避免极值压扁；48h 半衰模型，超 7 天淘汰
4. **四象限初判**：时效×垂直=爆款区（≤24h 出稿）；常青×垂直=长尾排栏目；
   时效×泛=蹭热慎入；常青×泛=不做
5. **合规红线**：灾难/事故类热点标 R 红线，只用于排查已排期内容是否撞车

分级：A 追（24-48h 内出稿）/ B 观察（次日复查扩散）/ C 淘汰 / R 红线。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `date` | string | ⬜ | 采集日期（默认当天） |
| `entries` | array | ✅ | 热榜条目：title / platform / heat / rank / hours_since |

条目来源：用户从各平台热榜手动转写或粘贴（本技能不做爬虫、不绕平台风控）。

## 输出规格

- `rows`：候选池（标题 / 收录平台 / 平台数 / 热度分 / 时效系数 / 赛道 / 得分 / 级别 / 备注）
- `summary`：采集日期 / 原始条目 / 合并后话题数 / 四级计数 / 平台分布
- 产物文件：`out/热点候选池.xlsx`、`out/热点平台分布.png`、`out/radar_scan.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 粘贴各平台热榜转写数据（含标题/热度/时间）
4. 得到候选池与四象限分级（语境判断与红线标记由模型完成）

### 方式二：带脚本（精确计算 + 产出 Excel）

```bash
python scripts/radar_scan.py --input input.json --outdir out
python scripts/radar_scan.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/热点候选池.xlsx` | 候选池（A 级行标红）/ 平台分布 / 汇总 |
| `out/热点平台分布.png` | 各平台采集条数柱状图 |
| `out/radar_scan.json` | 机器可读结果，供 hotspot-aggregate-scan-flow 读取 |

**分工**：脚本做归一化、衰减、合并、排序（不漏算）；模型做赛道匹配标定、
假阳性排除、红线复核。两者结果交叉核对，以脚本数值为准。

## 边界（不做的事）

- ❌ 不编造热榜条目或热度值——缺哪个平台的源就明说
- ❌ 不做爬虫、不绕平台风控、不抓取需登录的私密数据
- ❌ 数值计算以脚本输出为准，对话不口算
- ❌ 灾难/事故/政治敏感类热点不转选题（红线，无例外）
- ❌ 不为凑 A 级数量降低标准

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "date": "2026-09-30",
  "entries": [
    {"title": "00后整顿职场：拒绝无效加班从这3句话开始", "platform": "抖音", "heat": 1860000, "rank": 2, "hours_since": 9},
    {"title": "00后整顿职场，拒绝无效加班的3句话", "platform": "小红书", "heat": 92000, "rank": 5, "hours_since": 14},
    {"title": "某地突发地震，多地震感明显", "platform": "微博", "heat": 2100000, "rank": 1, "hours_since": 3}
  ]
}
```

**输出**（脚本实跑，12 条 → 10 个话题）：

| 级别 | 热点标题 | 收录平台 | 得分 | 备注 |
|---|---|---|---|---|
| A 追 | 00后整顿职场：拒绝无效加班从这3句话开始 | 抖音、小红书 | 101.8 | 跨 2 平台+垂直，24h 内出稿 |
| R 红线 | 某地突发地震，多地震感明显 | 微博 | 98.3 | 灾难类不蹭，仅排查撞车 |
| B 观察 | 国庆自驾游避堵攻略，这5条路线亲测 | 抖音、知乎 | 73.4 | 跨 2 平台但非本赛道 |
| C 淘汰 | AI剪辑工具横评：剪映映美vs必剪谁更强 | 抖音 | 38.0 | 超 48h 未扩散，半衰已过 |

汇总：A 级 1 / B 级 5 / C 级 3 / 红线 1；平台分布：微博 4、抖音 3、小红书 3、知乎 2。
