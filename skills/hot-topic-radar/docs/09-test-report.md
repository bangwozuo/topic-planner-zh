## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 数据来源 | 仅支持用户粘贴/转写热榜；不做爬虫、不绕平台风控 |
| 词表法局限 | 赛道词表未覆盖的新热词会漏标「垂直」，须模型按 prompt 复核 |
| 相似度合并 | 换写法幅度大的跨平台同话题（如完全换个梗名）可能漏合并 |
| 热度口径 | 各平台热度值口径不同，只做平台内相对比较（log10 归一），不做跨平台绝对比 |

## 四、结论

**通过。** 端到端实跑产出 Excel + PNG + JSON 三类真实文件；跨平台合并（×2）、
半衰淘汰（×3）、红线拦截（×1）、低热降级（×2）四类规则抽样核对 6/6 正确；
灾难热点在热度全场最高的情况下仍被合规拦截，符合「红线优先于流量」设计。
