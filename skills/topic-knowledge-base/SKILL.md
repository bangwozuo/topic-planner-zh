# 选题知识库

维护创作者的核心资产——选题库：候选选题的入库、查重标记、评分沉淀、
状态流转、发布后权重回写。

不做的事：不自动执行任何外部写入；AI 产出的全部变更先进入「待人工确认」
队列，创作者勾选后才生效。

## 元信息

| 字段 | 值 |

| 资产形态 | 纯提示词 + 本地库文件（Excel/CSV），无外部 API |

## 能力描述

1. **条目入库标准**：选题ID（T0001 永不复用）/ 标题 / 四来源 / 四象限 /
   三因子评分（≥70 冲 / 55-70 备选 / <55 弃）/ 状态 / 标签 / 权重
2. **状态流转 SOP**：候选 → 待人工确认 → 已入库 → 已排期 → 已发布 →
   已复盘；淘汰只改状态不物理删除；四个确认点（入库 08:00 / 排期周日 /
   发布前 / 复盘周一 09:00）
3. **只读连接器与降级路径**：平台热榜粘贴、竞品追踪 JSON、评论区导出、
   搜索下拉词截图转写——全部只读，降级路径明确到「粘贴文本」级
4. **权重回写规则**：权重分量 = min(爆款率÷0.1, 1.5)（1/10 基准 = 中性点），
   来源权重 = 0.7×分量 + 0.3×当前权重；爆款率基准 1/10；样本 <10 不调权；
   权重区间 [0.5, 1.5]
5. **库体检触发线**：重复率 >30% 换信息源；僵尸条目（候选超 60 天）清理；
   库总量 >200 条归档冷数据；淘汰占比 >40% 检查入库标准

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `operation` | string | ✅ | 操作类型：入库 / 查重标记 / 状态流转 / 权重回写 / 库体检 |
| `entries` | array | ⬜ | 操作对象条目（入库为候选选题；回写为来源统计数据） |
| `library` | array | ⬜ | 当前库文件内容（Excel/CSV 导出或粘贴） |

## 输出规格

- `operations`：库操作清单（操作 / 条目 / 选题ID / 理由）——**全部待人工确认**
- `summary`：库状态摘要（各状态分布 / 僵尸条目 / 来源权重）
- `need_confirm`：需人工确认逐条列表与默认建议

## 使用步骤

### 方式一：纯提示词（SOP 咨询与操作清单生成）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 说明操作类型并粘贴库文件内容 / 候选条目 / 复盘数据
4. 得到「待人工确认」的库操作清单，**勾选后自行更新本地库文件**

### 方式二：配合工作流（自动生成操作清单）

- 每日 08:00：`topic-lib-dedup-match-flow` 产出查重后的入库建议
- 每周一 09:00：`weekly-topic-review-flow` 产出权重回写建议
- 两者均汇入本技能的「待人工确认」队列，由创作者勾选执行

## 边界（不做的事）

- ❌ 不自动执行任何外部写入（平台后台、发布、删除）
- ❌ 不编造库内条目、不虚构「已复盘」状态
- ❌ 灾难/事故/政治敏感热点不入库；品牌蹭题只入「观察」
- ❌ 不物理删除条目——淘汰改状态并留原因
- ❌ 样本 <10 不调整来源权重
- ❌ 库为私有资产，不对外共享

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "operation": "入库+权重回写",
  "entries": [
    {"title": "面试被问期望薪资怎么答：3 个话术模板", "source": "搜索下拉词", "quadrant": "常青×垂直", "score": 68},
    {"title": "某地突发地震避险指南", "source": "平台热榜", "quadrant": "时效×泛", "score": 95}
  ],
  "source_stats": {"平台热榜": {"quarter": "Q3", "viral_rate": 0.14, "sample": 28, "weight": 1.0}}
}
```

**输出**（摘要）：

| 操作 | 条目 | 结论 |
|---|---|---|
| 新增入库 | 面试被问期望薪资怎么答 | ✅ 常青×垂直，评分 68 落在 55-70 备选区，待确认 |
| 拒绝入库 | 某地突发地震避险指南 | 🔴 灾难类红线，不入库（任何评分不能洗白） |
| 权重回写 | 来源「平台热榜」 | 分量 min(0.14÷0.1, 1.5)=1.4 → 0.7×1.4+0.3×1.0 = 1.28（样本 28 ≥10，可调） |

## 所属工作流

- `topic-lib-dedup-match-flow`（查重结果写入本库）
- `weekly-topic-review-flow`（复盘数据回写来源权重）

- 选题库为创作者私有资产，不对外共享、不上传公开渠道
- 引用的热榜/竞品数据注明来源与采集日期
