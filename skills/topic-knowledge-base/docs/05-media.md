## 操作清单

1. **读取客户列表**
   - 调用企业微信「获取客户列表」接口（`GET /cgi-bin/externalcontact/list`）
   - 传入参数：`access_token`
   - 返回字段：`external_userid` 列表

2. **获取客户详情**
   - 调用「获取客户详情」接口（`GET /cgi-bin/externalcontact/get`）
   - 传入参数：`access_token`, `external_userid`
   - 返回字段：`name`, `avatar`, `corp_name`, `follow_tags` 等

3. **筛选目标人群**
   - 根据业务规则（如标签、所属企业）对读取到的客户列表进行内存筛选
   - 产出待发送的 `external_userid` 列表

4. **构建消息体**
   - 确定 `msgtype`（如 `text`）
   - 组装 `text.content` 字段

5. **发送应用消息**
   - 调用「发送应用消息」接口（`POST /cgi-bin/message/send`）
   - 传入参数：`access_token`, `touser`, `msgtype`, `agentid`, 对应消息内容
   - 记录返回的 `msgid` 与发送状态
