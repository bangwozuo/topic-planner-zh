近期热帖集中在「冷启动获客」与「定价策略」两类话题，情绪整体偏积极。

### 示例 2：竞品动态追踪

**能力**：跟踪指定竞品账号更新并摘要

**输入**：

```json
{
  "source": "r/SideProject 近 7 天热帖 20 条"
}
```

**输出**：

## 要点摘要

开发者在冷启动期最缺的不是执行力，而是「在哪个渠道、对谁、说什么」的判断依据。

## 痛点清单

1. **选题无依据** — 凭感觉发内容，不知道哪条会有效（来源 1、3）
2. **渠道分散** — 同时维护 5 个平台，每个都做不深（来源 2）

## 情绪倾向

偏负面 — 多数帖子在描述「投入多但反馈少」的挫败感

## 证据索引

- 来源 1：日更 30 天，仅 2 条内容带来有效转化
- 来源 2：5 个平台来回切，最后都荒废

**资产位置**：`skills/competitor-track/`

### 示例 3：选题去重校验

**能力**：语义级比对候选选题与历史库

**输入**：

```json
{
  "brief": "面向独立开发者的性能优化工具，主打启动速度从 8 秒降到 0.3 秒"
}
```

**输出**：

## 钩子文案

我们花了 3 个月，把启动时间从 8 秒压到 0.3 秒。

## 切入角度

用具体的数字对比制造冲击力，开发者对性能数字高度敏感。

## 目标受众

关注性能优化的独立开发者与前端工程师。

**资产位置**：`skills/topic-dedup-check/`

### 示例 5：爆款标题锻造

**能力**：按平台风格批量产出候选标题

**输入**：

```json
{
  "product_info": {
    "名称": "冰丝防晒衣",
    "材质": "锦纶 + 氨纶",
    "卖点": [
      "UPF50+",
      "可拆卸帽檐"
    ]
  }
}
```

**输出**：

## 优化后标题

夏季冰丝防晒衣 男女同款 轻薄透气 UPF50+ 防晒外套 可拆卸帽檐

## 卖点清单

1. **UPF50+ 硬防晒** — 可提供检测报告编号
2. **冰丝凉感材质** — 锦纶 + 氨纶混纺，客服可提供成分表
3. **可拆卸帽檐** — 一衣两穿，通勤与户外通用

## 合规扫描

- 结论：**通过**
- 违规词：无（已规避「最好」「第一」「国家级」等极限词）

**资产位置**：`skills/viral-title-craft/`
