### 执行摘要（真实输出）

```text
选题包 6 条（热点机动位 3/3（上限 30%），常青 2），跳过 0 条
```

### 规则核验

| 规则 | 实测 |
|---|---|
| 机动位 ≤30% | 热点候选 4 条，第 4 条（时效×泛，match 0.2）降「机动位候补」✅ |
| 常青×泛跳过 | 本样本无此象限，机制在 skip 分支存在（缺字段/常青×泛均入跳过说明）✅ |
| 3 标题 3 公式 | 数字锚点/反差悬念/疑问钩子各 1，含字数与合规状态 ✅ |
| 数字提取修正 | 「00后整顿职场」正确取「3」（跳过 0 开头的 00）✅ |
| 不硬凑 | 候选为空 → 占位正常退出（分支实测）✅ |
| 不自动发布 | 产物仅草稿包，人工确认点在 summary 中明示 ✅ |

## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 标题模板化 | 句式草稿通顺度有限（如截断的短语拼接），必须人工润色终稿 |
| 配额参数 | total_slots 缺省时不限制热点比例，建议每次传入当期配额 |
| 受众细化 | 未传 audience 时统一「账号核心粉丝」，颗粒度粗 |
| 来源枚举 | 新增选题来源需同步扩充 ANGLE_MAP，否则兜底痛点瞬间 |
